INFRATECH

Uma plataforma inteligente para monitoramento de hardware em servidores de jogos online desenvolvida para garantir visibilidade, estabilidade e alta disponibilidade em ambientes de gaming.

// SOBRE O PROJETO

O QUE É A INFRATECH?

A INFRATECH é um sistema de monitoramento de hardware voltado para servidores de jogos online. O projeto foi idealizado e desenvolvido como trabalho de conclusão de curso na São Paulo Tech School, com foco em resolver um problema real enfrentado por operadores de servidores de games: a falta de visibilidade sobre o estado da infraestrutura física.

Através de nossa solução nos servidores, o sistema coleta métricas de CPU, memória, rede e armazenamento, consolidada dos dados em um painel centralizado e emite alertas quando limites críticos são atingidos.

FUNCIONALIDADES PRINCIPAIS

COLETA

Agente de Coleta

Um agente leve instalado em cada servidor captura métricas de hardware em intervalos configuráveis — sem interferir na performance das aplicações em execução.

PROCESSAMENTO

Dados Processados

Um agente leve instalado em cada servidor captura métricas de hardware em intervalos configuráveis — sem interferir na performance das aplicações em execução.

ALERTAS

Sistema de Alertas

Um agente leve instalado em cada servidor captura métricas de hardware em intervalos configuráveis — sem interferir na performance das aplicações em execução.

DASHBOARD

Painel de Controle

Interface centralizada acessível apenas para usuários autenticados. Exibe o estado da frota de servidores, histórico de eventos e relatórios de disponibilidade.

SEGURANÇA

Acesso Controlado

Nenhum dado de servidor é exposto publicamente. Todo acesso ao painel exige autenticação, e as permissões são gerenciadas por perfil de usuário.

RELATÓRIOS

Relatórios de SLA

Geração de relatórios periódicos com métricas de uptime, incidentes registrados e comparativo de performance entre períodos definidos.

COMO FUNCIONA

01

Cadastro e Configuração

O administrador cria sua conta, registra os servidores da frota.

02

Instalação do Agente

Um Client é instalado em cada servidor. Ele coleta dados de CPU, RAM, disco e rede.

03

Processamento Centralizado

O backend recebe, valida e armazena as métricas a cada ciclo de coleta.

04

Acesso ao Painel

O usuário acessa o dashboard para visualizar a infraestrutura e os relatórios.
