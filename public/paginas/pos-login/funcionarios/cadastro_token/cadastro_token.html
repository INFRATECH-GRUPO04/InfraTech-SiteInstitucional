Como o token funciona

O token fica vinculado à empresa conectada e ao perfil escolhido na próxima etapa.

A quantidade informada define quantos cadastros podem usar esse código. Cada cadastro concluído consome uma utilização; ao atingir o limite, o token não aceita novos cadastros.
